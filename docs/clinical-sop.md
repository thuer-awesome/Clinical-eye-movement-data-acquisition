# 临床操作 SOP（简版）

## 采集前

1. 确认受试者已完成知情同意和院内数据授权；只使用脱敏编号，不在备注中填写姓名、身份证号或病历号。
2. 固定头箍、镜头和 IR 光源，打开双眼实时预览。
3. 先利用 V2 预览中央的“眼眶正对范围”做镜头粗调，再按每只眼箭头和文字微调：未锁定时先把整只瞳孔移入画面；置信度不足时检查焦距、曝光、睫毛遮挡和角膜反光。框线由当前真实置信度从红色过渡到黄色、绿色；掉线或检测帧过期时会回到灰色。范围框和颜色本身都不是检测结果，进入框内或变绿不代表门禁已完成。
4. 等待两只必需眼位都显示“对准完成，可以开始采集”，并保持不动直到进度条完成。仅有画面或帧率通过而瞳孔未达标时，开始按钮仍不可用。
5. 页面顶部必须显示“现场采集”，两路必需设备通过预检；帧率低于合格线时不要开始。
6. 更换 USB 口、相机或机械位置后，重新执行设备扫描和方向确认，并重新完成瞳孔对准。

## 开始与进行中

1. 填写受试者编号、访视编号、操作员；年龄和性别按研究方案决定是否记录。
2. 选择采集方案和筛查标签，勾选知情同意确认，点击“开始采集”。
3. 观察两路画面、实时 FPS、黑帧、写入帧数和瞳孔捕捉/对准状态。预览偶尔刷新慢不等于原始录制丢帧，以页面指标和最终质量报告为准。
4. 保持头部和相机位置稳定，不要在采集中拔插 USB 或打开其他相机软件。
5. 页面显示“正在重连”时不要立刻强制退出；等待有限重连结束。成功会继续当前会话，失败会自动安全结束并保留已写数据。

## 结束与导出

1. 点击“结束并保存”，等待页面回到可复核状态；不要直接关闭浏览器或强制结束进程。
2. 检查 `quality.json` 对应的 FPS、黑帧、写入帧数和瞳孔有效率，并打开 `pupil_report.json` 或 `*_pupil_preview.jpg` 快速确认检测结果。交接时同时查看每只眼 `quality_filter.rejected_reason_counts`；若 `pupil_too_small`、`ellipse_too_elongated`、`pupil_not_fully_exposed` 或 `temporal_jump` 占比异常，先复核原始 AVI、焦距和照明/佩戴状态，不要把拒绝样本当作有效数据。
3. 在“已完成会话”点击“导出 ZIP”，确认页面显示完整本机路径；需要时复制路径或下载 ZIP。
4. 将 ZIP 按院内命名、访问控制和备份政策转移；不要把 ZIP 上传到公开 issue、聊天或个人网盘。
5. 病理/情绪备注只作为研究/筛查记录，不能写成诊断结论。

## 异常处理

- 页面显示帧率不足、设备错误或帧流超时：停止当前会话，保存已有记录，检查 USB/驱动/照明后点击“重新检查”。
- 旋转看起来未生效：确认相机卡片同时显示所选 `frame_transform` 和“方向已验证”；它证明像素变换已进入预览、检测和写盘链路。仍需用实际眼部画面人工确认上下/左右，错误时停止录制后重新保存方向设置。
- 点击停止后长时间无响应：等待有限超时完成；若会话进入 `error`，保留目录并把 `clinical_capture.log` 和 `quality.json` 交给维护者，先脱敏再共享。
- 发现左右眼反了：不要靠浏览器刷新；停止采集，在设备设置重新映射和保存。
- 任何疑似数据泄露、未授权设备动作或真实受试者信息进入日志的情况，立即停止外发，按院内隐私流程和 `SECURITY.md` 联系维护者。
